# MVP Requirements

1. Support at least three isolated pilot tenants.
2. One tenant represents one pilot business.
3. Each tenant has one shared business configuration.
4. A tenant may create multiple agents.
5. Agents use only their tenant’s approved business information.
6. Users can test an agent through the browser.
7. Tests produce a transcript, recording, summary and outcome.
8. The system can capture messages and appointment requests.
9. The system must not invent confirmed bookings.
10. Cross-tenant access must be prevented.
